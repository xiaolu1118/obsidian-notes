# AI 智能体技术全景与分阶段学习主计划

> 执行版已统一到 [[Agent学习执行总表与视频导航]]。本文保留技术全景与选课依据；日程有差异时以执行总表为准。

## 当前个人背景与规划口径

用户确认：Android 系统框架开发有基础；Python 有一定基础，可跳过基础语法，在项目中补齐；AI 智能体仍是小白。目标为手机厂 AI 智能体与应用开发方向，逐步对标专家岗位。

此前直接将工程化训练营列为首选过早。本主计划取代前序互相调整的学习顺序：先建立 AI 基础认知，再学习模型应用、工具执行、RAG/上下文与编排，最后做工程化和 Android 专项。保留历史笔记作资料，不把 Android 经验等同于 LLM/Agent 基础。

时间按每周 10—12 小时、16 周估算，不是就业承诺；阶段以验收推进。用户尚未确认预算、班型、每周时间和具体课程，以下均为建议。

## 1. 先理解系统关系

LLM 接收输入和上下文，生成文字或结构化调用建议。工具由程序实现并实际执行。Agent 宿主管理工具、状态、权限、预算与继续/停止条件，让模型能够依据执行反馈决定下一步。

最小链路：目标 → 上下文 → 模型 → 普通回答或工具调用 → 程序校验/授权/执行 → 工具结果回传 → 模型继续或结束。

固定工作流由代码预先确定路径，自主 Agent 由模型在约束下决定部分执行路径。两者可以结合。聊天应用、RAG 和 Agent 是不同能力组合：检索可作为固定问答流程，也可作为 Agent 工具。多 Agent 是后续架构选项，不是入门前置条件。

## 2. 技术全景

| 层次 | 作用与概念 | 初期实践选项 | 学习深度 |
| --- | --- | --- | --- |
| 模型基础 | LLM、Token、上下文窗口、采样、幻觉、训练/推理、Embedding | 模型平台控制台、官方 SDK | 能解释能力与限制，暂不训练模型 |
| 模型应用 | 消息/角色、提示、示例、结构化输出、流式、超时/限流、费用 | Python、HTTP/SDK、JSON Schema、按需 Pydantic | 独立调用和解析，理解接口差异 |
| 工具执行 | Function Calling、工具描述、参数校验、授权、幂等、结果反馈 | Python 函数、工具注册表、受控执行器 | 首轮重点，自己完成执行循环 |
| 上下文/记忆 | 对话历史、任务状态、摘要、用户偏好、持久化 | SQLite、文件、后续 Android Room | 区分历史/状态/长期记忆，处理隔离与更新 |
| RAG | 解析、切块、关键词/向量检索、Embedding、重排、引用 | 先关键词，后选一种本地向量检索方案 | 理解每步作用，能定位检索与生成错误 |
| 工作流/规划 | 路由、状态机、条件分支、检查点、人工介入、预算 | 先普通代码，后选 LangGraph 等一种框架 | 能说明选择工作流还是 Agent 的理由 |
| 工具生态 | MCP 客户端/服务端、工具发现、认证授权 | 后期把已有工具做一次适配 | 协议不是 Agent 本身，也不替代权限检查 |
| 应用服务 | 流式接口、会话、存储、配置、部署 | FastAPI、SSE、SQLite/PostgreSQL、Docker | 先最小服务，按需要补后端知识 |
| 评测/安全 | 数据集、成功率、Trace、回归、错误操作、注入、敏感数据 | Python 脚本、结构化日志，按需平台 | 从首个工具开始记录，后续系统化 |
| Android 执行 | Kotlin、协程/Flow、UI 状态、Binder/AIDL、权限、系统接口 | Android Studio、Room、独立进程服务 | 通用 Agent 基础成熟后迁移 |
| 端侧/端云 | 模型加载、资源调度、量化概念、路由、回退、隐私、功耗 | 一种本地运行时、统一模型接口、Perfetto | 目标岗位专项，真机测量 |
| 多模态 | ASR/TTS、语音打断、图片/屏幕理解 | 平台语音能力或模型 API | 文本主链路成熟后添加 |

框架举例并非唯一选型；不要求同时掌握全部。微调、强化学习、算子/NPU 优化和多 Agent 仅在项目瓶颈或目标 JD 明确要求时深入。

## 3. 培训课程如何使用

公开大纲适配判断，不是教学质量排名。2026-10-24 核对官网与官方索引；部分页面正文未提取成功，不能承诺详细节次、更新、价格和辅导服务。以下按主题映射，不编造精确课号。

### 入门主线候选：慕课网 Agent 从 0 到 1

[官方课程](https://coding.imooc.com/class/925.html)。已知先修为开发经验与 Python 基础，与用户起点较一致。优先试听能否从 LLM/API/工具调用循序进入项目；如早期依赖大量未解释框架，则不满足当前需要，暂不购买。

适用阶段：模型调用、基础工具执行与第一轮完整项目。完整目录和实际代码仍需进一步核对。

### 基础替补：尚硅谷或黑马的 AI 模块

- [尚硅谷](https://www.atguigu.com/agent/)：大模型应用、LangChain/RAG 和 Agent 项目，作为讲解不足时的替补资源。
- [黑马](https://aiapp.itheima.com/)：大模型应用、Agent/RAG 模块可作备选；不为已有 Python/Java 能力重学整套课程。

仅选一家作为补充，不重复学两个完整就业班。能否单独购买、试听或按阶段学习要核实；不能把平台搭建项目当作手写执行器的替代。

### 进阶：极客时间 AI 工程化项目实战营

[官方介绍](https://u.geekbang.org/subject/10/1010551)。公开介绍要求 Python 后端和大模型基础。完成单 Agent 项目并理解状态、工具与检索后再考察，用于工程化、评测、监控与部署；不是当前入门起点。

### 暂后置：小林 coding 全量路线

[课程介绍](https://www.xiaolincoding.com/project/llm_offer.html)。公开路线有较早的模型结构/训练内容，作为需要原理深度和项目辅导时的备选；只有能按应用主线定制时才考虑提前。

### 免费/官方补充

- [李宏毅中文概念课](https://speech.ee.ntu.edu.tw/~hylee/ml/2025-spring.php)：生成式 AI、AI Agent、模型内部逻辑三个主题。
- [Hugging Face 中文 Agent 课程](https://github.com/huggingface/agents-course/blob/main/units/zh-CN/unit0/introduction.mdx)：概念复习与术语。
- [AI Agents in LangGraph](https://www.deeplearning.ai/courses/ai-agents-in-langgraph)：执行循环、状态与人工介入的代码补充。
- [Evaluating AI Agents](https://www.deeplearning.ai/courses/evaluating-ai-agents)：Trace 和实验方法。

每阶段以一门主课为准，其他只在概念不清时查阅。中文视频优先解决认知，英文资料按可用讲稿辅助，不预设中文字幕。

## 4. 16 周详细执行计划

贯穿项目：学习资料与待办助手；始终使用虚构/脱敏数据。先命令行，再服务端，再 Android，避免同时调试新 AI 概念与手机平台问题。

| 周次 | 学习内容 | 跟学资源主题 | 动手任务 | 验收 |
| --- | --- | --- | --- | --- |
| 1 | LLM、Token、上下文、幻觉、训练与推理 | 李宏毅生成式 AI；主课大模型基础 | 对比有上下文/无上下文问答，整理 10 个术语 | 能说明模型为何不知道私有资料、为何输出可能不同 |
| 2 | Agent、工具、工作流和 RAG 的关系 | 李宏毅 Agent；主课架构认知 | 画 3 张图：聊天、检索问答、工具执行；准备 5 条笔记与 10 个任务 | 明确模型与宿主的责任，不把 RAG 等同于 Agent |
| 3 | SDK/HTTP、消息、提示与结构化输出 | 主课模型调用部分 | 写命令行调用、JSON 解析、脱敏日志，观察格式错误和超时 | 解释完整请求响应，不依赖隐藏封装 |
| 4 | 多轮与流式、上下文预算、异常 | 主课对话/API 部分 | 实现命令行多轮助手、历史裁剪、取消及限次重试 | 多轮连贯，不无限增长或无限重试 |
| 5 | Function Calling、Schema、参数校验 | 主课工具调用；LangGraph 从零 Agent 部分 | 实现 search_notes，只读搜索闭环 | 回答基于真实工具结果，非法工具和参数被拒绝 |
| 6 | 多步任务、授权、幂等、预算 | 主课 Agent 项目 | 加 list_todos/create_todo、执行前确认、操作 ID、循环上限 | 拒绝不写入，重复操作不重复创建，结果未知先查询 |
| 7 | RAG 解析、分块、Embedding 与检索 | 主课 RAG 入门；不足时查尚硅谷/黑马 AI 模块 | 先关键词基线，再对小资料集做分块与向量检索 | 能独立查看召回片段，并解释 Embedding 与生成模型区别 |
| 8 | 混合检索/重排概念、引用和无答案处理 | 主课 RAG 实战 | 固定问题比较检索方式，增加引用和无证据回答策略 | 定位检索漏召回与生成误读，不伪造引用 |
| 9 | 上下文、任务状态、持久化与隔离 | 主课记忆/编排 | 用 SQLite 保存会话与任务，隔离会话 | 重启可恢复，状态恢复不盲目重放工具 |
| 10 | 图编排、检查点、人工介入；MCP 选学 | 主课编排或 LangGraph 对应章节 | 选择一种框架重做同一链路，和手写版本比较 | 解释框架解决什么问题，能导出执行轨迹 |
| 11 | FastAPI、SSE、配置与最小部署 | 项目配套后端内容 | 封装现有助手服务，管理凭据和会话，客户端鉴权 | 本地终端可调用，断开连接有明确行为，密钥不提交 |
| 12 | 固定数据集、组件/端到端评测、对照实验 | 极客工程化适配评估；官方评测课补充 | 30 条起步案例，记录成功/错误操作/耗时，改一个变量对比 | 能复现结果并解释失败，确定是否需要工程化训练营 |
| 13 | Kotlin 模型接口与执行器、协程/Flow | Android 官方文档，自编迁移实验 | 先假模型测试，再通过受保护服务接云模型，展示执行状态 | 与 Python 基线任务行为一致，APK 无长期云密钥 |
| 14 | Android Room、生命周期、Binder/AIDL | Android 专项自编实验 | 持久化任务并将一个工具拆为服务，测试断连/重建 | 不重复执行副作用，权限校验和取消路径明确 |
| 15 | 一种本地模型运行时、能力与路由 | 本地运行时官方文档 | 接入摘要/分类，测试离线、模型不可用、端云回退 | 记录设备/版本/加载/延迟/内存，上传数据受策略约束 |
| 16 | 语音入门或性能专项，作品交付 | 按目标 JD 选择一个 | 优先评测、失败复盘和架构报告；有余力再加语音 | 演示、代码、评测和三项取舍完整，不以功能数替代质量 |

第 12 周工程化训练营如实际课量较大，应延长计划，不强行压入一周。16 周按自学主线估计，培训班独立进度需另行整合。首个工具阶段起即做基本日志、权限和案例检查，第 12 周是系统化评测，并非首次验证。

## 5. 前两周每天怎么学

### 第 1 周

- 第 1 天：看中文生成式 AI 视频首段，记录 LLM/Prompt/Token/上下文，写下一个不懂的问题。
- 第 2 天：继续观看，整理训练、推理和幻觉的区别；给同一问题不同上下文观察变化。
- 第 3 天：了解消息与角色，设计同一问题的三种提示，记录差异。
- 第 4 天：阅读主课基础目录与试听，确认老师是否解释术语、是否提供代码练习。
- 周末：画最小模型应用数据流，做一页术语表。精确 Token 数用平台计量，不以字符数简单替代。

### 第 2 周

- 第 1 天：看中文 Agent 视频，标出模型、工具与环境。
- 第 2 天：画“用户请求—模型调用建议—程序执行—结果反馈”的链路。
- 第 3 天：区分固定工作流与自主决策，分别写一个适用场景。
- 第 4 天：了解 RAG 是把外部资料检索进上下文；理解它可以是工具或固定流程。
- 周末：准备 5 条虚构笔记、10 个任务，定义允许做和禁止做的动作。选主课，仍不必开始 Android 项目。

## 6. 培训班最终筛选方法

带着自己的背景询问：我熟悉 Android Framework，Python 有基础，AI/Agent 从零。请提供从 LLM/API 开始的样课、到工具调用和状态管理的作业路径、代码批改样例，以及完整费用/服务期。是否必须先学大量训练原理，或重复通用编程基础？

适配优先于机构名：模型基础能讲明白；工具循环能亲手实现；后续有状态、检索、评测；有足够练习与反馈。只列大量技术名词或主要搭平台，不满足本路线。
