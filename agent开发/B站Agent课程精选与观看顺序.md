# B 站 Agent 课程精选与观看顺序

> 当前统一执行顺序见 [[Agent学习执行总表与视频导航]]；本文作为课程资源与核验说明。

## 适用起点与核验边界

Android Framework 与基本 Python 有基础，AI/Agent 零基础。先建立模型/Agent 认知，再学 API、工具、RAG 与编排。2026-10-24 检索视频页面、B站索引与原课程来源。

部分 B 站视频直读返回 412，未核验完整评论区、全部播放器和配套文件，因此不能宣称已验证“评价最好”或好评率。以下按来源、课程结构、可检索的学习热度与个人适配度筛选。播放量是索引快照，不等于人数或教学质量。公开视频不保证模型/API 实验免费。

## 推荐 1：李宏毅生成式 AI 与 Agent 概念课

- [B 站：2025 春季课程合集](https://www.bilibili.com/video/BV1YeT7zBEPi/)
- 2026-10-24 已整理：[[李宏毅2025机器学习课程视频导读]]、[[李宏毅2025机器学习核心知识详解]]；依据官方课件辅助整理，非逐字字幕摘要。
- [原课程官网](https://speech.ee.ntu.edu.tw/~hylee/ml/2025-spring.php)

已检索选集：生成式 AI 第一讲、Agent 原理第二讲、语言模型内部机制第三讲。分别建立基础概念、工具/规划认知、模型能力边界。

建议先看前两讲，第三讲按需选看，训练和架构专题暂后置。B站版本为个人上传，未确认授权，不能称为老师官方账号。

验收：画出模型与工具交互，解释 Token、上下文、幻觉、Agent 与工作流。

## 推荐 2：黑马大模型 RAG 与 Agent 项目实战——当前主课

- [B 站直达](https://www.bilibili.com/video/BV1yjz5BLEoY/)
- [本次可检索的视频列表页](https://www.bilibili.com/list/ml3936243324?bvid=BV1yjz5BLEoY&oid=115931552416097)

视频自述从提示词、LangChain 到 RAG/Agent 项目，适合作为第一门编程主线。2026-01-21 发布，本次列表页索引显示约 375 万播放；不将此解读为学习人数或好评率。列表容器可能属于收藏者，不把收藏夹名称视为原 UP 主，具体发布者以视频页为准。

按模型接入 → 提示词 → RAG 基础与项目 → Agent 执行与项目推进。章节精确编号以当前目录为准，不依赖未经核实的转载目录。

每阶段作业：独立请求响应、替换自有假资料、查看召回片段、增加一个工具并记录实际执行。先按课程依赖运行，再讨论升级；课程代码不自动代表生产级方案。

## 推荐 3：黑马 LangChain + LangGraph + LangSmith——进阶补充

- [B 站直达](https://www.bilibili.com/video/BV178w1z7EHQ/)

公开视频介绍包含 Agent、LangGraph，以及 LangSmith 监控、调试和评估。索引显示 2026-03-20，约 7 小时 18 分；时长为索引快照。本次没有核验全部课节，不保证逐节覆盖所有故障恢复或授权场景。

验收：能解释一次错误发生在哪个节点，记录工具参数、结果和耗时，检查状态保存与恢复方式。

## 针对个人的观看安排

| 阶段 | 主看内容 | 产出 |
| --- | --- | --- |
| 第 1—2 周 | 李宏毅前两讲，配合术语复习 | 模型、工具、RAG、工作流关系图 |
| 第 3—4 周 | 黑马主课的模型与提示词部分 | 命令行调用、多轮、结构化输出与脱敏日志 |
| 第 5—6 周 | 黑马主课 RAG 部分 | 小型学习资料知识库、检索片段与引用 |
| 第 7—8 周 | 黑马主课 Agent 部分 + Hello-Agents 选看 | 工具调用助手、执行预算、确认与错误处理 |
| 第 9—10 周 | 黑马 LangGraph/LangSmith + 上下文工程选看 | 状态、Trace、任务集与回归报告 |
| 后续 | Android 主计划 | Kotlin 接入、系统工具、本地推理 |

上述为按课程播放结构的 B站跟学安排；RAG 与工具入门顺序可交叉，并不要求先精通 RAG 才能实现 Agent。每周 10—12 小时估计，练习时间应多于观看时间。部分异常处理作业需要自己补充，不能假定视频全部提供。

## 如何验证课程是否适合自己

- 先看导学、一个核心代码课和一个项目课。
- 能否解释请求、执行和结果回传，是否仅展示最终效果。
- 看近期技术提问及回复，尤其是依赖错误、资源缺失和模型接口变更。
- 能否拿到可运行配套，版本是否明确；第三方学习仓库不冒充官方源码。
- 不使用“全网最好”“七天就业”等标题作为评价证据，不因集数多就优先。
