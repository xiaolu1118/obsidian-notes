# 市面 Agent 培训课程调研与选课建议

## 结论与核验范围

> 最新澄清：用户虽有 Android 与 Python 基础，但 AI/Agent 仍从零开始，不能直接跳入工程化营。当前建议为：先用中文概念课和从模型/API 起步的项目课程入门；极客工程化营后置。以 [[AI智能体技术全景与分阶段学习主计划]] 为最新依据，下文历次优先级仅供追溯。

2026-10-24 搜索机构官网与课程官方页面。已找到国内面授、录播和训练营形态的通用 Agent 课程。未核实到能够完整覆盖 Android Framework、端侧推理、系统工具执行及评测的国内成套培训班；这不表示市场不存在。

以下为机构自述的课程内容，不是教学质量、就业结果或讲师履历的独立背书。公开页面存在不代表某一期仍招生；具体开班、有效服务与价格需要书面确认。未联系机构、提交个人资料或购买课程。

## Android 专项线索

- [Ship an LLM in an Android App](https://sotaaz.com/courses/ship-llm-android)：搜索索引提及 Kotlin/Compose、MediaPipe、前台服务与设备加速；页面正文抓取失败，交付、师资、价格及是否完整视频均未核实。仅列待核实线索，不作购买推荐，也不能等同于系统级 Agent 培训。
- [Android 官方 ADK 文档](https://developer.android.com/ai/adk?hl=zh-CN)：官方文档介绍 Android 的 Kotlin/Java Agent 集成，可作为专项补充；不是商业培训班，也不表示所有国内手机厂采用这一方案。

## 面向个人的选课策略

用户是 Android 系统框架工程师，AI/Agent 按初学者准备，但不是编程零基础。优先选择面向在职开发者、可以跳过通用基础、具有代码作业和反馈的课程。单课先试听，确认需要外部督学与批改后再考虑训练营。通用班补 Agent，Android 专项另用自己的终端项目承接。

选择标准：从 API 与工具执行起步，有状态持久化、取消、幂等、失败恢复、评测与部署。Coze/Dify 作为一部分可以，但不能仅靠搭工作流证明 Android 系统级智能体能力。

## 给机构的咨询模板

我有 Android 系统框架开发经验，目标是手机厂端侧/系统级 Agent 岗位，AI 与 Python 按初学者准备。请提供：

1. 当前在售版本的详细课表、每阶段课时、先修要求和最近更新日期。
2. 是否能跳过 Java/Web 等已有基础，单独学 LLM 与 Agent 阶段。
3. Function Calling、状态管理、取消、幂等、失败恢复、评测分别有哪些代码作业。
4. 是否有真实 Android/Kotlin、Binder/AIDL、本地推理和端云路由项目；请给章节与演示，而不是只说明“支持移动端”。
5. 直播/录播比例、每周时间、谁答疑、是否逐份批改代码、反馈时限。
6. 完整费用、API/GPU/设备额外费用、有效期、退款与延期条款；低价体验是否另购正课。
7. 能否先看一节完整技术课、作业要求及脱敏批改样例。

## 下一步待办

## 个性化筛选结论（2026-10-24）

> 用户后续确认：已有一定 Python 基础，基础语法课程可以跳过，其余知识在项目实践中按需补齐。此信息取代此前按 Python 初学者制定的前置安排；Python 后端、异步、部署等能力尚未确认。

### 基于已确认 Python 基础的最新优先级

- 首选考察：极客时间 AI 工程化项目实战营。其工程化方向更贴近已有 Android 工程经验；不再要求先修 Python 语法课，但仍需确认 Python 后端及 LLM 基础要求能否通过入营预习/首个项目补齐。此为大纲适配判断，不是师资或付费推荐。
- 第二候选：慕课网 Agent 从 0 到 1 项目课。若希望按自己的节奏先完成一轮项目，可优先试听该单课；完整章节、更新与答疑仍需验证。
- 条件备选：小林 coding。仅在能将路线聚焦 Agent 应用、状态管理、评测与部署，且辅导机制合适时考虑；训练原理不作为近期必修。
- 尚硅谷、黑马：整套基础班仍不优先；可单独提供合适 AI 项目阶段时再比较。

下面保留早期比较背景；凡涉及先补 Python 语法的建议均已由上述确认替代。

在预算、在职状态和 Python 水平尚未确认的情况下，暂按保留现有 Android 工程积累、以 AI 初学者逐步转型、不重学整套基础就业班来选择。以下是适配判断，不是机构质量排名，也不是付费决定。

### 建议顺序

1. 当前优先试听慕课网 Agent 从 0 到 1 单课：主题聚焦，适合作为第一轮完整跟练候选。新增检索显示课程先修含“有开发经验、Python 基础”，因此修正此前容易被误解的“零基础”说法：AI 零基础不等于 Python 零基础，应先补 Python。完整章节、更新与反馈仍需核对；未充分核实，不能直接推荐付款。
2. 补完基础后重点考察极客时间 AI 工程化实战营：公开描述中的工具调用、Agent、监控与工程交付更贴近从工程师升级的需要；但 Python 后端和模型基础门槛更高，不作为目前第一步。
3. 小林 coding 训练营作为需要系统辅导和更深模型知识时的备选：公开路线将模型结构与训练放在较早阶段，短期对准手机厂应用工程目标时有投入分散风险；若能定制为应用、工具执行、评测和部署主线，适配度会提高。
4. 尚硅谷与黑马整套班暂不优先：均可补基础，但 Python/Java/Web、全栈和平台操作与个人已有能力及手机厂专项存在一定错位。仅当接受独立 AI 模块、有代码评审、合适在职班型且实际试听良好时重新考虑。

若用户需要强制进度、逐份代码批改而非主要录播，慕课网的优先级不一定成立：应先确认实际辅导机制，再比较训练营，而不是按“零基础”宣传决定。

### 手机厂方向共同缺口

尚无足够公开证据确认上述候选完整覆盖 Kotlin Agent、Binder/AIDL 服务、系统能力注册授权、本地模型资源调度、端云隐私路由和设备功耗/温升评测。因此任何通用班都需要补 Android 实战项目。

### 最终付款前的三个实质验证

- 索取完整试听：工具调用如何校验、工具执行结果如何回传、失败如何处理。
- 索取一份作业及脱敏批改样例：确认有代码反馈，而非仅提供答案与群聊。
- 对照手机厂 JD 确认专项支持，取得总价、服务范围、有效期和退费的书面说明。

- [ ] 明确预算、所在城市、是否接受面授与每周时间。
- [ ] 从候选中挑 2—3 家，获取同一格式课表和完整报价。
- [ ] 对照目标 JD 核验模块覆盖与 Android 专项缺口。
- [ ] 试听后再决定，不把宣传就业数据作为个人结果保证。
